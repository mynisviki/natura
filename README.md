# NATURA — hero-секция интернет-магазина

Адаптивная hero-секция для магазина натуральных товаров NATURA. Свёрстана на чистом HTML и CSS — без фреймворков и UI-китов.

**🔗 Демо:** https://mynisviki.github.io/natura/

## Возможности

- **Full-bleed фон** — фотография товаров во всю ширину, шапка поверх неё.
- **Типографика по бренд-гайдам** — Playfair Display для заголовков, Montserrat для интерфейса.
- **Бренд-палитра** на CSS-переменных (тёмно-зелёный, шалфейный, бежевый, молочный, графит).
- **Блок преимуществ** — три пункта с иконками (лист, росток, коробка), текст выровнен по низу; мягкое молочное «гало» не даёт иконкам и подписям сливаться с фото.
- **Адаптив** — десктоп / планшет / мобайл; на мобильном фото уходит под молочную вуаль для читаемости.
- **CSS-only бургер-меню** — раскрывается анимацией `grid-template-rows`, без JavaScript.
- **Доступность** — семантические теги, `aria-label` у интерактивных элементов, видимый фокус (`:focus-visible`).

## Стек

- HTML5
- CSS3 (Grid, Flexbox, custom properties, `clamp()`, media queries)
- Google Fonts: Playfair Display, Montserrat

## Структура

```
natura/
├─ index.html        # разметка: шапка + hero
├─ styles.css        # стили, токены, адаптив
└─ assets/
   └─ hero.jpg       # фоновое фото
```

## Запуск локально

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
# Python 3
python3 -m http.server 8000
# или Node
npx serve
```

Затем открыть http://localhost:8000/
